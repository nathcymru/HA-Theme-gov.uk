# Design a clearer home

<div class="c-lead">Use civica.uk styles, components and patterns to make Home Assistant clear, consistent and easier to use.</div>

This is the design system for the HA-Theme-gov.uk repository. It adapts UK public service design to a home control interface, using the supplied civica.uk identity. It is independent of GOV.UK and Home Assistant.

## Start with the task

Make the most useful action easy to find. Show what the home is doing now, what changed and what the user can do next. Use familiar words and visible labels. Keep complex controls available without filling every page with them.

## Ten palettes, one interface

Choose Civic Cobalt, Racing Moss, Imperial Damson, Sovereign Crimson, Regimental Plum, Oxford Midnight, Ink Charcoal, Heritage Ochre, Kiln Terracotta or Umber Bronze. Each has Vivid and Muted variants. [Explore the colour system](styles/colour.html).

A palette changes brand surfaces and emphasis. It does not change the meaning of an error, an energy series or a warning.

## Evidence and limits

This site defines the implementation contract and local design decisions. Automated checks are evidence about specific behaviours; they are not a certification of the whole Home Assistant interface. [Read the compatibility and verification limits](get-started/compatibility.html).
