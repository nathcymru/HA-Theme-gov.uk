# Icons and images

Home Assistant uses repeated visual recognition. Icons, device images, room photos, weather symbols and camera feeds can support real tasks.

## Icons

Use Home Assistant's existing icon vocabulary where possible. Keep an icon's meaning consistent. Pair a device icon with its name and state; a coloured bulb alone does not say which light it controls or whether it is available.

Use visible text labels for unfamiliar actions. Icon-only controls require a meaningful accessible name and an adequate target. Tooltips supplement that name; they are not the only explanation.

Do not recolour all icons to the selected palette. Preserve semantic warning and error colours, manufacturer-identifying artwork where appropriate and meaningful native domain state colours.

GOV.UK explicitly recognises that icons can help people scan systems they use frequently. It still recommends visible labels in most cases. [GOV.UK images guidance](https://design-system.service.gov.uk/styles/images/)

## Images

Use room/device images when they help identification. Use live camera imagery only in its established security or monitoring context, with a visible location and freshness/state indicator. Do not add stock photography to fill empty space.

Describe informative images with alternative text. Give decorative images empty alternatives. Do not repeat every surrounding word in alt text. Keep text as real text rather than embedding device state or instructions in a bitmap.

[NHS image guidance](https://service-manual.nhs.uk/design-system/components/images) provides evidence for meaningful imagery helping people orient themselves. [Home Office guidance](https://design.homeoffice.gov.uk/design-system/styles/images) supports consistent illustration and purposeful photography without unnecessary effects.

## Brand images

Use supplied civica.uk assets as files. Preserve proportions and clear space. The asset pack's proof and automated checks are references; inspect final rendering at actual mobile and desktop sizes. [Brand rules](brand.html)
