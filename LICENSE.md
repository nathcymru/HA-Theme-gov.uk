## Map data and external services

Map examples use data from © OpenStreetMap contributors under the [Open Database Licence](https://www.openstreetmap.org/copyright). The visible attribution remains on the map. Map tiles are requested from the OpenStreetMap Foundation only after you select **Load map**. The provider receives the information needed to handle those requests, such as your IP address.

The examples use normal browser caching and do not download maps for offline use or request your location. Check the [OpenStreetMap vector tile policy](https://operations.osmfoundation.org/policies/vector/) and [OpenStreetMap privacy policy](https://osmfoundation.org/wiki/Privacy_Policy) before using that service in your own installation. A data licence does not provide unlimited tile-server access.

civica provides theme components and Home Assistant integration templates. It does not supply API keys, access tokens or hosted integration endpoints. You must obtain your own credentials where required, keep them private and comply with each provider's terms of service, usage limits and applicable licence. Public example tile URLs belong to their external provider; civica does not operate them.

Do not include credentials, private camera images, device names or household locations in public examples or issue reports. Example household values are synthetic unless an explicit provenance record states otherwise.

## Cookies and site information

This documentation site uses one essential cookie to remember that you have hidden the first-visit notice. It does not use analytics or advertising cookies. Hiding the notice is an acknowledgement, not consent to optional tracking or acceptance of licence terms.

| Cookie | Purpose | Duration |
| --- | --- | --- |
| `civica_docs_notice` | Remembers the notice version you have hidden; contains no account or household details | Up to one year |

The cookie is set only when you select **Hide this notice**. It is limited to the documentation site's path. It uses `SameSite=Lax` and `Secure` on HTTPS. Clearing this cookie in your browser makes the notice appear again. It is not shared across browsers or devices.

If your browser blocks storage, you can hide the notice for the current page. It may appear again when you navigate or return. With JavaScript off, the notice remains visible and all licence information is still readable. The site does not save accordion example choices.

GitHub Pages hosts this site. GitHub may keep service logs under its own [privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). This is separate from civica's browser storage. External links and map requests are subject to the destination provider's policies.
